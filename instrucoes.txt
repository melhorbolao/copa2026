ESPECIFICAÇÃO TÉCNICA: CHAVEAMENTO RADIAL (RADIAL BRACKET - A COPA)

Objetivo: Substituir a visualização inicial da página "A Copa" (/src/app/a-copa/page.tsx) por um diagrama de chaveamento circular (Radial Bracket) semelhante a uma teia, convergindo os 32 times classificados para o centro (a Taça). 

1. TECNOLOGIA DE RENDERIZAÇÃO (SVG OBRIGATÓRIO):
- É expressamente proibido tentar montar essa estrutura usando HTML/CSS Grid/Flexbox convencional.
- Crie um componente dedicado chamado '<RadialBracket />' que retorne um único elemento '<svg>' responsivo (usando 'viewBox', ex: viewBox="0 0 1000 1000").
- A lógica interna do componente deve utilizar funções trigonométricas nativas do JavaScript (Math.cos, Math.sin) para calcular as coordenadas (x, y) dos nós (partidas) e desenhar as linhas conectores (<path> ou <line>) em anéis concêntricos.

2. ESTRUTURA DO TORNEIO (COPA 2026):
- Anel Externo (16 avos de final): 32 nós (16 do lado esquerdo, 16 do lado direito).
- Anel 2 (Oitavas): 16 nós.
- Anel 3 (Quartas): 8 nós.
- Anel 4 (Semis): 4 nós.
- Anel 5 (Final): 2 nós convergindo para a imagem/ícone central do troféu.

3. ESTADO E PREENCHIMENTO DINÂMICO:
- O componente deve cruzar os dados com a tabela de 'matches'.
- Se o time/seleção ainda não estiver definido para aquela posição no chaveamento, renderize um placeholder neutro (ex: um círculo cinza claro com borda tracejada e uma sigla genérica, como "1A" ou "Vencedor Jogo 73").
- Assim que o banco de dados registrar a classificação de uma seleção, o nó correspondente no SVG deve ser preenchido (utilize a tag <foreignObject> dentro do SVG para renderizar a bandeira e o nome da seleção usando componentes React/Tailwind normais por cima da coordenada do nó).

4. COMPORTAMENTO MOBILE E RESPONSIVIDADE:
- Como o SVG completo possui muitos detalhes, no celular os nós ficariam microscópicos se a tela encolhesse demais.
- Encapsule o <svg> em uma div 'wrapper' com as classes Tailwind `w-full overflow-x-auto touch-pan-x`. Isso permite que no desktop a teia apareça por completo e, no mobile, o usuário possa deslizar lateralmente para explorar os dois lados da chave sem perder a nitidez.

5. VERIFICAÇÃO INDEPENDENTE OBRIGATÓRIA:
Antes de escrever o arquivo completo, apresente no terminal:
A) A função matemática (em TypeScript) que você criará para distribuir os 32 nós do anel externo pelas bordas do círculo.
B) A estrutura de dados (array de nós) que vai mapear os match_ids do Supabase para suas respectivas coordenadas (x, y) no diagrama.
C) O trecho de código que usa `<foreignObject>` para garantir que as bandeiras/avatares sejam renderizadas corretamente sobre as coordenadas do SVG.
